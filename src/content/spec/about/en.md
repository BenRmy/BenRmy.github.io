# About

This site is a place for notes worth keeping: concrete problems from AI application work, reverse engineering write-ups, and the occasional engineering judgment call.

## The site

- **Astro**, fully prerendered to static HTML
- **Swup** for page transitions without full reloads
- **pagefind** for search, indexed at build time with no backend
- Hosted on **GitHub Pages**, deployed on every push to `main`
- Bilingual, Chinese by default

Source lives at [BenRmy/blog](https://github.com/BenRmy/blog).
